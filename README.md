## Selected Computational Projects

My computational work connects statistical physics, Monte Carlo sampling and machine learning through numerical experiments, algorithm comparisons and analysis of statistical uncertainty.

### [Spin Glass Annealing](https://github.com/flavio-m-ricci/spin-glass-annealing)
**ML-assisted sampling and optimization · Python / PyTorch · Group project**

Compared simulated annealing, population annealing and neural-network-assisted global annealing for disordered Ising systems. The project combines a MADE autoregressive model with Metropolis–Hastings acceptance and local Monte Carlo updates, and examines optimization performance and fixed-temperature sampling.

### [Placental DWI Classification](https://github.com/flavio-m-ricci/placental-dwi-classification)
**Scientific machine learning · Medical imaging · Individual project**

Developed a modular Python pipeline for feature extraction and supervised classification from placental diffusion MRI. Compared linear, kernel, tree-based and neural models using stratified group cross-validation, with preprocessing fitted within training folds, and documented the uncertainty and limitations of a 69-subject cohort.

### [XY Spin Glass](https://github.com/flavio-m-ricci/xy-spin-glass-parallel-tempering)
**Monte Carlo simulation · C++17 / Python · Individual project**

Implemented a three-dimensional XY spin-glass simulation combining parallel tempering, Metropolis updates and over-relaxation. Reproduced selected analyses from the literature at reduced scale, including an equilibration consistency check and finite-size correlation-length analysis, with explicit discussion of statistical limitations.

### [Statistical Physics and Machine Learning](https://github.com/flavio-m-ricci/statistical-physics-and-machine-learning)
**Learning theory experiments · Python · Coursework**

Implemented numerical studies of polynomial regression, perceptron learning and generalization. Extended the prescribed coursework with a supplementary investigation of update noise in a teacher–student perceptron model, supported by numerical results, figures and reports.
